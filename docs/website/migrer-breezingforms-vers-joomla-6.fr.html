BreezingForms de Crosstec n’est plus maintenu depuis 2022 et ne fonctionne pas sous Joomla 6. BreezingForms NG en est la suite communautaire, reconstruite pour Joomla 6 et PHP 8.3+. Il s’installe par-dessus votre composant BreezingForms et conserve vos formulaires, soumissions, scripts et pièces.

Ce qui est conservé

  • Les formulaires créés en QuickMode, avec leurs éléments, thèmes, e-mails et paramètres de paiement.
  • Toutes les soumissions (enregistrements), scripts, pièces et règles de l’intégrateur : ils restent dans les mêmes tables #__facileforms_*.
  • Les éléments de menu, les permissions et la configuration du composant, migrés automatiquement.
  • Les URL et le code stockés qui pointent vers option=com_breezingforms, réécrits vers le nouveau composant.
  • Le code PHP personnalisé qui utilise les anciennes classes BF*, grâce au plugin système BreezingForms NG - Compatibilité.

Ce qui change

  • Seul QuickMode subsiste : les formulaires créés en Easy Mode ou Classic Mode doivent être reconstruits en QuickMode.
  • Le rendu mobile a disparu : utilisez la mise en page Bootstrap 5 ou « une page », toutes deux adaptatives.
  • Le code personnalisé qui appelle d’anciennes API Joomla (JFactory, JRequest, getQuery(true)…) doit être mis à jour pour Joomla 6.
  • Le code d’envoi personnalisé doit transmettre le jeton de formulaire Joomla.

Étape par étape

  1. Sauvegardez les fichiers et la base de données, et travaillez d’abord sur une copie du site.
  2. Repérez vos formulaires Easy Mode et Classic Mode : il faudra les reconstruire.
  3. Ne désinstallez pas l’ancien composant BreezingForms : l’installateur NG a besoin de son entrée d’extension pour le migrer, et la désinstallation risque de supprimer ses données.
  4. Mettez Joomla à jour en version 6 (PHP 8.3 ou plus). L’ancien composant peut cesser de fonctionner à ce stade : laissez le site hors ligne jusqu’à l’étape 5.
  5. Téléchargez la dernière version de BreezingForms NG et installez-la via Système → Installer → Extensions, par-dessus le composant existant.
  6. Vérifiez que le plugin système BreezingForms NG - Compatibilité est activé si vos formulaires contiennent du code PHP personnalisé.
  7. Testez chaque formulaire : captcha, envoi de fichiers, e-mails, paiements en mode test (sandbox) et exports des enregistrements.
  8. Activez le débogage de Joomla et cherchez les erreurs Class … not found dans administrator/logs/everything.php : elles signalent du code personnalisé qui appelle encore une API supprimée.

Besoin d’aide ?

Ouvrez un ticket sur GitHub. Les développeurs peuvent consulter les notes techniques de migration (en anglais), avec les équivalents Joomla 6 des anciennes API.
