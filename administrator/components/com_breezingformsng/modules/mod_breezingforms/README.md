# BreezingForms NG module

Site module for Joomla 6 and PHP 8.3+. Requires `com_breezingformsng`.

Installed or updated with the component. In Joomla Site Modules, select BreezingForms NG, enter the internal name of a published form, choose a template position and menu assignment, then publish the module. Forms can render inline or in an iframe. Module caching is disabled because forms depend on the request and session.

The module uses the NG form engine, including its existing module context identifier `mod_facileforms`. This identifier is part of the engine protocol. The imported Git history is preserved.
